# Product Discovery Coach

A Claude skill that helps Product Designers deeply understand the product they're building — business logic, user behavior, technical constraints, and strategic context.

Built by [@tawand.r](https://www.threads.net/@tawand.r)

---

## What it does

Guides designers through structured product exploration using 5 understanding layers (What → Who → How → Why → So what), with 4 additional modes for specific needs:

- **Explore** — onboard to a new product or feature through layered questioning
- **Test** — check your own understanding using Feynman technique and scenario testing
**Propose** — get UI/UX direction grounded in mental models and product context
- **Competitor Lens** — analyze competitors beyond the visual layer
- **Pre-meeting Prep** — generate sharp questions before PO / CTO / dev meetings

After each session, the skill outputs two persistent files:
- `product-knowledge.md` — a growing knowledge base about your product, carried across sessions
- `session-log.md` — a concise log of insights, blind spots, and action items

---

## Requirements

- [Claude](https://claude.ai) desktop app (Cowork mode) or Claude Code
- Skill files: `SKILL.md` + `references/` folder

---

## Installation

1. Download `product-discovery-coach-en.skill`
2. Open Claude desktop app → Cowork mode
3. Drag and drop the `.skill` file to install

---

## Usage

Trigger phrases: *"help me understand this product"*, *"explore this feature"*, *"review this UI"*, *"prepare for my meeting with PO"*, *"analyze this competitor"*, or simply share a PRD, wireframe, screenshot, or meeting notes.

---

## What to prepare

Any product documents work — PRD, wireframes, screenshots, meeting notes, website links. Messy is fine.
